# DK Job Search Bot

Telegram-бот для поиска вакансий на датских job-сайтах по ключевым словам.

## Источники данных

- **Jobindex.dk** — через официальный RSS-поиск (`/jobsoegning.rss?q=...`)
- **Jobnet.dk** — через недокументированный BFF-эндпоинт сайта
  (`jobnet.dk/bff/FindJob/Search`). Это не официальный публичный API — сайт
  может поменять его в любой момент без предупреждения. Если поиск по
  Jobnet перестанет что-то находить, это первое место для проверки.
- **IT-jobbank.dk** — тот же движок/формат RSS, что у Jobindex, но с уклоном
  в IT-вакансии.

Все три источника независимы: если один упадёт или заблокирует запрос,
остальные два продолжат работать (см. `bot/search.py`).

## Возможности бота (текущий MVP)

- `/keywords SQL, reporting, data quality` — задать свои ключевые слова
  через запятую
- Загрузка CV — просто отправить файл (.pdf/.doc/.docx) документом в чат
- `/location Aarhus` — необязательный фильтр по городу (простое совпадение
  подстроки в поле локации вакансии — см. "Известные ограничения" ниже)
- `/search` — запустить поиск по сохранённым ключевым словам; бот
  запоминает, какие вакансии уже присылал этому пользователю, и не
  дублирует их в следующий раз

## Чего пока нет (следующие шаги)

- Сопоставление CV с вакансией (% совпадения) и генерация ansøgning —
  требует вызова LLM (Claude API) из самого бота, для этого понадобится
  отдельный API-ключ Anthropic
- Автоматическая еженедельная рассылка (сейчас поиск запускается только
  по команде `/search`)
- Более точная геофильтрация для Jobindex/IT-jobbank (сейчас — грубое
  совпадение подстроки по названию района; Jobindex умеет искать по
  правильному geoareaid, но нет готовой таблицы город → geoareaid)

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # и вписать туда токен от @BotFather
python3 -m bot.main
```

## Структура проекта

```
bot/
  config.py       # переменные окружения, пути
  storage.py      # SQLite: ключевые слова, путь к CV, уже показанные вакансии
  search.py        # объединяет все источники, дедуп, гео-фильтр
  handlers.py       # обработчики команд Telegram
  main.py            # точка входа
  sources/
    jobindex_rss.py  # Jobindex.dk + IT-jobbank.dk (общий RSS-формат)
    jobnet.py         # Jobnet.dk BFF API
```
